## 🚀 About the Event

CommitCon moves beyond traditional prototype hackathons and unverified pitch decks. The sprint focuses on developing **production-ready Free and Open Source Software (FOSS)** supported by continuous automated testing, atomic Git commit histories, and OSI-compliant licensing.

- **Venue**: Block 32 (Event Arena), Lovely Professional University, Phagwara, Punjab
- **Fee**: ₹199 per participant
- **Target Audience**: 1000+ LPU Engineering Students

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vishant-kataria/commitcon.git
   cd commitcon
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
